### 비용과 해석

12개 고정 케이스와 Q09 수정 재실행은 기존 compare 단계 공유 원장에 기록됐습니다. 12건에서 생성 모델 12회·검토 모델 7회, 수정 실행에서 생성 모델 1회가 호출됐으며, 해당 작업 증분 추정 비용은 **$0.11401260**, 미확정 비용은 $0입니다. 앞선 3대상 smoke의 $0.00843060을 포함하면 이 문서 두 실험 합계는 $0.12244320입니다. 총액은 사용 토큰 가격 기준 추정치입니다.

이번 실험은 RAG 문헌의 제조업·Agentic 적합성을 검토 모델이 일관되게 심사한다는 주장을 뒷받침하지 않습니다. 대부분의 제안은 실행 전 검사에 멈췄고, 검토 LLM은 미완료 또는 인용 검증 오류가 많았습니다. 실제 제조 문헌과 Agentic 실패 연구를 더 모으는 일 외에도, ① 제조 자료의 도메인 매핑·출처 태그, ② 위험별 Agent 연구의 도구 경로 매핑, ③ 검토 모델의 출력 근거 제한에 대한 계약, ④ 실패 시 제안·검토 중간 결과를 보존하는 관측 기능이 먼저 보완되어야 합니다.

## 검색·검토 병목

1. `MANUFACTURING` 도메인 검색은 이 실행에서 주로 `TECH-NIST-OT`, `TECH-ISA95-MOM`, `TECH-ORACLE-ASL` 같은 기술·운영 자료를 반환했습니다. 사고 검색에서는 BP Texas City 자료가 나왔지만, 제조 도메인 검토 단계의 인용으로 사용되지 않았습니다. 품질의 `LIT-KOBE-REPORT`도 검색 후보에 있었으나 생성 제안이 선택하지 않았습니다.
2. `AGENTIC` 검색은 거의 모든 위험에 `RES-AGENT-SAFETY` 하나를 반환했습니다. 이 연구는 일반적인 실패 범주를 뒷받침하지만, 공급 자격 조회나 `assign_operation` 재시도처럼 위험별 선언 도구의 동작을 충분히 설명하지 않습니다.
3. 생성 모델은 `AMBIGUOUS_WRITE` 영향 문구를 구매·생산·품질 사이에 제대로 바꾸지 못했습니다. 구매의 “과잉 재고”를 생산 일정·품질 출하 제안에 복사했습니다.
4. 검토 모델을 부르기 전 코드 사전검사가 “관련된 제조 사고 자료 + Agent 실패 연구 + 채택 정책”의 실질 적합성을 확인하지 못하는 상태에서, 출처 ID의 카테고리·태그·정책 채택 조건으로 보류했습니다. 이는 과잉 생성보다 안전한 동작이지만, 의미 검토 자체의 성능은 이번 기록으로 측정할 수 없습니다.

## 다음 개선 항목

- 제조 사고 자료를 위험 주장에 맞게 매핑하고, 승인 대기와 사고 자료의 역할을 분리합니다. `source-register.json` 후보들은 팀 도메인 검토 전이므로 현재 RAG 근거로 간주하지 않습니다.
- 위험별 Agentic 연구 근거를 늘리고, 논문의 일반 분류만 인용할 때는 도구·권한 경로와의 연결을 제안 근거에서 별도 설명하게 합니다.
- `business_impact`를 Agent 유형별 채택 정책에서 만들고 모델이 타깃 간 문구를 복사하지 못하도록 검사합니다.
- 12개 고정 케이스를 다시 실행할 때 각 케이스 입력·형태학 변수·검색 인덱스 해시를 고정하고, 생성 실패/코드 보류/의미 검토/실행 연결을 서로 다른 비율로 보고합니다. 근거 수용 후에만 검토 LLM이 실제 호출되므로, 의미 평가 통과율은 별도로 집계해야 합니다.
