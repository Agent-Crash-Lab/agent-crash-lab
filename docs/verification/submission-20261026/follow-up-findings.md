## Oracle 13건의 전체 분모

- 정상 4건: PASS 2건, INCONCLUSIVE 2건. 잘못된 FAIL 0/4.
- 위반 8건: FAIL 4건, 잘못된 PASS 4건.
- 환경 오류 1건: ERROR 1건.
- 기대 결과 일치 7/13. 보류·오류를 분모에서 제거하지 않았습니다.

이는 생산 시뮬레이터에서 scripted 행동 11건, 관측 객체 변조 2건을 사용한 결과입니다. 이번 실제 구매 MCP·PostgreSQL 6건과 같은 환경의 성능 지표로 합산하지 않습니다. MCP 조사 클라이언트를 연결하지 않은 OB 시험에서 후속 조사 AttributeError가 기록된 경우도 원문에 남겼습니다. 해당 조사 단계를 통합 성공으로 계산하지 않았습니다.

조사 보고서 10건은 정상 1건 허용, 잘못된 9건 중 7건 거부·2건 수용입니다. ‘보고서 80% 정확도’처럼 실제 LLM의 문장 품질로 표현하지 않습니다.

종료 뒤 쓰기·최종화 경쟁 조건 등 과거 평가 항목은 이번 35건과 구매 6건으로 해결됐다고 선언하지 않습니다. 별도 동시성 시험을 다음 조건으로 둡니다.
