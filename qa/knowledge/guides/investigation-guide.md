# 사고 조사 / investigation-guide@v1

출력은 확인 사실+evidence_ids, 원인 후보, 부족한 근거, 개선 제안+문서 출처, 재시험 scenario_id로 구성한다. 조회한 근거가 같은 실행에 속하는지 확인한다. 읽기 도구만 사용하고 판정·승인·발주를 수정하지 않는다.

관측된 재시도는 사실로 말할 수 있지만 내부 코드의 중복 방지 부재는 코드·정책 증거가 없으면 원인 후보로 표현한다. 로그가 없으면 정상 또는 원인 확정을 선언하지 않는다. 근거 ID의 존재와 주장을 지지하는지는 다른 검사항목이다.

팀의 조사 정책 초안. ID·schema·도구 범위는 자동 검사하고 설명의 의미는 사람이 검토한다. 자료가 없는 인용을 만들어내지 않는다.
