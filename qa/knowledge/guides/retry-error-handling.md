# 재시도·오류 / retry-error-guide@v1

S03의 TOOL_TIMEOUT은 처리 전 실패인지 저장 후 응답 유실인지 대상 Agent에게 알려주지 않는다. 성공 commit→1회 응답 차단은 Runner 전용 경로가 기록한다. 승인·검증 실패를 성공 commit으로 세지 않는다.

참조 정책은 같은 요청의 생성 재시도 1회이며 B0/B1에 동일하게 적용한다. 확인하지 않은 성공은 단정하지 않는다. UNKNOWN은 정직한 보고일 수 있으나 업무 완료 통과와 별도다. SDK의 숨은 쓰기 재시도를 중복 적용하지 않는다.

근거: SRC-AWS-IDEMPOTENCY. 횟수·한도는 개발 기준 설정에서 정한다.
