# QA 자료

실행 코드 패키지가 아니라 시험에 필요한 양식·지식·예시·공개 표본을 모은 곳입니다.

| 폴더 | 내용 |
|---|---|
| `contracts/` | 공통 대상·계획·이벤트·판정 양식 |
| `knowledge/` | 위험 템플릿·조사 지침·출처 목록 |
| `examples/` | 현재 구매 참조 대상·도구·초기 상태·시험·정답 사건 |
| `reference/` | 실제 공개 자료 표본. Agent의 정답은 아님 |

폴더별 별도 설명 대신 [데이터 안내](../docs/data-guide.md)에서 파일·사용 코드·생성 방법을 함께 봅니다. 제품 설계와 세 참조 유형은 [설계 안내](../docs/architecture.md)에 있습니다.
